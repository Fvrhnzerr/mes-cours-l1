Bienvenue 👋 Installation du site

La base de données est prête. Crée ton compte de propriétaire. On te demande une seule fois un jeton GitHub : il prouve que le site t'appartient et permet d'y ranger les fichiers des cours. Il reste caché sur le serveur.

Comment obtenir un jeton GitHub ?
  1. Sur GitHub : ta photo de profil → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Expiration : choisis la plus longue possible (ou « No expiration »).
  3. Repository access : « Only select repositories » → mes-cours-l1.
  4. Permissions : Contents = « Read and write », et Actions = « Read-only ».
  5. Clique sur Generate token, copie-le et colle-le ci-dessus.

Utilisateurs

Crée un compte pour chaque professeur, puis envoie-lui son identifiant et son mot de passe. Un compte marqué « sans mot de passe » vient de l'ancienne version : clique sur « Nouveau mot de passe » pour l'activer.

Nouveau compte

Créer plusieurs comptes d'un coup

Une ligne par prof : Nom ; Matière. Le même nom sur deux lignes donne un seul compte avec deux matières.

Un professeur peut ajouter et supprimer des cours. Un administrateur peut en plus gérer les comptes, les réglages et les sauvegardes. Supprimer un compte le déconnecte immédiatement.

Sauvegardes

Une sauvegarde contient les comptes, les réglages, la liste des documents et le journal. Les fichiers des cours, eux, sont gardés avec tout leur historique sur GitHub.

Chargement…
⬇️ Télécharger les données

Historique

Une sauvegarde automatique est faite chaque jour où un administrateur se connecte (les 30 dernières sont gardées). Les sauvegardes manuelles restent jusqu'à ce que tu les supprimes. Avant chaque restauration, l'état actuel est sauvegardé automatiquement.
