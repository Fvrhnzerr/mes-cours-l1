Connexion du propriétaire (jeton GitHub)
  1. Sur GitHub : ta photo de profil → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access : « Only select repositories » → mes-cours-l1.
  3. Permissions : Contents = « Read and write », et Actions = « Read-only ».
  4. Clique sur Generate token, copie-le et colle-le ci-dessus.

Utilisateurs

Crée un compte pour chaque professeur, puis envoie-lui son identifiant et son mot de passe.

Créer plusieurs comptes d'un coup

Une ligne par prof : Nom ; Matière. Le même nom sur deux lignes donne un seul compte avec deux matières. Supprime une ligne pour ne pas créer ce compte.

Nouveau compte

Un professeur peut ajouter et supprimer des cours. Un administrateur peut en plus gérer les comptes. Pour bloquer complètement quelqu'un : supprime son compte, crée un nouveau jeton sur GitHub et supprime l'ancien, connecte-toi avec le nouveau jeton, puis clique sur « Nouveau mot de passe » pour chaque compte restant.
