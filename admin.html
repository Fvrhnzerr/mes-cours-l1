Connexion

Colle ton jeton d'accès GitHub. Il reste sur cet appareil et n'est jamais écrit dans le site.

Comment créer mon jeton ?
  1. Sur GitHub : ta photo de profil → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Nom : « Drive admin ». Expiration : 1 an (ou ce que tu préfères).
  3. Repository access : « Only select repositories » → mes-cours-l1.
  4. Permissions → Repository permissions : Contents = « Read and write ». Facultatif : Actions = « Read-only » pour voir l'avancement de la publication ici.
  5. Clique sur Generate token, copie-le et colle-le ci-dessus. Ne le partage avec personne.
